# 📉 Customer Churn Predictor

An interactive Machine Learning application for predicting telecom customer churn.

## 🚀 Live Demo

👉 https://masmi-customer-churn.streamlit.app/

## What It Does

- Analyzes customer churn data
- Uses 7,032 customer records
- Compares Logistic Regression, Random Forest and Gradient Boosting
- Evaluates Accuracy, Precision, Recall, F1-score and ROC-AUC
- Provides interactive customer prediction
- Displays churn risk through Streamlit

## Model Result

Gradient Boosting achieved the strongest overall ROC-AUC of approximately **0.841**.
